# web-dev

Web development domain plugin for the Dónal + Claude agent hierarchy. Enable for front-end and web application projects.

## Components

**Agents:** senior-front-end (Opus) — front-end systems, design tokens, CSS architecture; staff-ux (Opus) — UX flows, trust/clarity assessment

**Routing:** Registers the Front-End Reviewer (`web-dev:senior-front-end`) for front-end signals and the UX Reviewer (`web-dev:staff-ux`) for UX signals. The Front-End Reviewer and the UX Reviewer backstop each other within this plugin; both can escalate to the Staff Engineer (`coordinator:staff-eng`) for architectural concerns.
