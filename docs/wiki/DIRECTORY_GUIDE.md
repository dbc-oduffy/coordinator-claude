# Wiki Directory Guide

Generated by /distill 2026-05-06-13h00. Updated by /update-docs 2026-05-18.

**Row-authoring convention:** a flat sibling page links bare (`[name](name.md)`). A page split
into `docs/wiki/<name>/README.md` plus sibling body files links to `<name>/README.md` (the
generated index), never a bare `<name>.md`, which is not a valid path for a split page. The
split's body files are `<name>`'s internal structure and get no separate top-level row.
